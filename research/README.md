# [산정 근거와 확인 기록]

[가정별 산정 근거](ASSUMPTION_LEDGER.md)는 관측 사실·Base 선택 이유·다른 조건·가정을 바꿀 자료를 연결한다. 수치와 계산은 [입력 JSON](../data/research_inputs.json), [공시 대사](../data/actuals_audit.csv), [출처](../data/source_register.csv)에 있다.

가격 비교는 2026-10-16 NAVER 일별 시세다. 거래소 공식 가격과 완전한 대사는 끝나지 않았다. 같은 날짜 관측 TTM peer는 ISC 1곳이고 정상 forward peer 평균은 산정하지 않았다. WACC·ke는 시나리오 조건이며 시장 CAPM 추정치로 표시하지 않는다.
